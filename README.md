# AI Tutor API

AI Tutor API is a FastAPI-based project that provides JWT authentication, AI-generated study material, and multimedia learning tools using Google Gemini.

## Features

- User signup and signin with JWT authentication
- MongoDB-based user storage
- Text-based lesson generation
- Academic image analysis
- Audio answer evaluation
- Video analysis with MCQ generation
- PowerPoint analysis and study-note generation
- Secure protected API routes
